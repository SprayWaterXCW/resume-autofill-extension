# 刷新恢复验证：0.6.5

日期：2026-10-05。仅记录机制、结果码和数量，不记录用户资料值。

## 故障证据

普通 Chrome 的京东方表单在刷新后显示“此页面已被某个扩展程序屏蔽”及 `ERR_BLOCKED_BY_CLIENT`。Agent 面板仍保留上一轮的 18 个写入字段、3 次模型调用和本标签页网络保护。

代码中的规则包含 `main_frame` 并按 `tabId` 持续生效。上一次修复使恢复按钮能够清理规则，但任务完成后的保护仍覆盖刷新请求，解释了再次被屏蔽。

本轮先通过原有恢复入口移除规则，再刷新错误页；实际浏览器重新出现京东方的教育、实习等表单区块。

## 修复

- 增加本轮表单精确 URL 的 GET 顶层重载交接规则，允许新文档及资源加载。
- 执行工具绑定安装保护时的真实 documentId，拒绝向同 URL 的替换文档写入。
- 本轮标签页加载时立即取消旧任务并关闭模型连接；结束后清理旧规则、扫描及计划。
- 清理不注入替换后的新文档；关闭标签页也清理；其他标签页更新不解除本轮保护。
- 两条规则的安装、完整条件核验和清理统一处理，清理过程串行化。
- 面板将旧计数标为刷新前结果，恢复入口改为“恢复正常浏览”。

## 验证

81 项 Node 测试通过；扩展构建成功。Chrome 扩展管理页实际显示 0.6.5，权限保持不变。
