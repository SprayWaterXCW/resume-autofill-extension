# 获奖级别与等次：0.7.1 验证记录

## 本轮范围

在独立 Agent 目录内增加逐条获奖/竞赛级别和等次，保留原文与当前分类。用户稍后补充实际级别。原插件目录没有修改，本轮未向真实招聘页面填写或提交。

## 实现

- 私有 awardDetails 与对应原文关联，保存、重开、备份导入都保留。
- 级别与等次分别建立事实路径，同一条记录的名称、级别、等次共享记录身份。
- 通用等级投影只用于选项控件，实际候选决定使用范围或等次；缺失与歧义有具体中文诊断。
- 工具契约限制获奖维度和明确记录位置，程序再次检查，执行后持续回读。
- 修复 Agent 所用解析副本对单条项目符号记录的处理差异。
