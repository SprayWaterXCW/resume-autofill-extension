## 资料库新增与仍需填写的内容

| 招聘页问题 | 正常资料编辑页入口 | 处理原则 |
| --- | --- | --- |
| 期望税前月薪 | 求职偏好 → 期望月薪（税前） | 独立金额或区间优先；未注明周期的旧金额不猜测月薪/年薪 |
| 生源地 | 联系方式与地址 → 生源地省/市/区县 | 与籍贯独立，不根据学校或现居地推断 |
| 色盲/色弱、海外院校毕业 | 基本信息对应选项 | 未确认时留空，不默认否或无 |
| 在读专业类别 | 对应教育经历 → 专业类别 | 使用该条教育记录明确填写的类别 |
| 研究方向、导师 | 每条教育经历的对应输入 | 不使用学校、专业或其他联系人的值代替 |
| 第二志愿、推荐人、内推码、可面试城市 | 求职偏好对应输入 | 与第一志愿、联系人和工作地点分开 |
| 其他语言能力 | 语言能力中的非英语语言记录 | 只汇总明确的非英语记录；只有英语时保持空白 |
| 获奖时间 | 获奖/竞赛每条卡片 → 获奖时间 | 不从奖项名称中的年份猜出日期；保留已有日期精度 |
| 项目中本人职责 | 每条项目经历 → 项目中职责 / 本人贡献 | 与项目整体描述和角色名称独立 |
| 正式工作、当前薪资 | 工作经历；求职偏好 → 当前薪资 | 不把实习强行转为正式工作；不借期望薪资 |
| 工作经验年限 | 基本信息 → 工作年限 | 不按年龄或实习次数推断；应届或无正式工作也需要用户明确填写 |
| 兴趣爱好 | 技能与亮点 → 兴趣爱好 | 没有资料时留空 |
| 论文/专著字段 | 论文与专著 → 单篇记录 | 标题、日期、期刊、作者顺序、期次分别保存 |
| 公司额外问题 | 自定义表单问答 → 问题原文与我的答案 | 按规范化后的原题匹配；听说过与参加过不等同 |

新增属性和空卡片不会产生推测事实。结构化论文、获奖日期、自定义问答等已用虚构数据做保存、导入、投影和语义验证；当前真实资料缺少这些值，因此不能声称已通过它们的真实网站填写验收。附件上传及声明等继续由用户手动完成。

## 测试证据与限度

回归覆盖完整日历、组合获奖范围、资料往返、日期精度、明确薪资周期、区间排版与歧义、跨轮来源占用、局部重试、异步表单就绪、控件替换、只读锁定的回读以及现有值保护。

0.7.24 全量回归为 202 通过、1 失败；失败是新增民族检查，未被当作通过。修正作用域后，19 项专项测试通过；随后一次全量仍有一个多标签页测试调度失败。该测试独立运行 6 项通过，检查发现其等待按 150 次事件循环而非时间预算结束，已改为最多 5 秒有界等待，保留原来的隔离、停止、迟到回复与写入目标断言。

0.7.25 最终全量回归为 **203 通过、0 失败**，构建通过。锁定回归同时覆盖原值保持、值被改动、空锁定字段不可取得凭据、只读字段不可再次写入。测试断言没有为了通过而删除。

0.7.26 发布前的全量回归发现两个既有案例失败：籍贯限制阻止普通文本框使用明确的籍贯城市。随后保留原有「23 个字段正确填写」和停止前零写入的预期，允许普通文本/原生选项使用明确籍贯层级，复杂地区控件仍使用完整投影；45 项针对性回归通过。验证完成前未将这份修改加载到真实页面，扩展更新情况见当前验证状态。

最终补齐原始月薪与投影在原生选项、自定义下拉和单选中的共同区间处理；新增执行回归验证相同区间不同排版可以选中，相近区间不能代替。**最终全量 204 项通过、0 项失败，构建通过。** 各轮脱敏数值证据见 [JSON 记录](observed-omissions-2026-10-06.json)。
