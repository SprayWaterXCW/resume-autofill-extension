# 0.7.6：真实页面反馈驱动的控件修复

## 范围与证据

本轮在普通 Chrome 中观察用户打开的招聘表单，通过既有 Agent 入口运行并读取执行记录。真实资料值与网页截图不写入本报告、源代码或测试夹具。修改仅在 `RESUME_AGENT`，独立插件目录没有改动。

证据包括：只读扫描元数据、本地服务的闭合诊断、弹窗逐项执行结果、Chrome 元素面板中日期输入节点的属性，以及生产执行器在虚构布局中的回归。无提交、投递、签名或最终申请行为。

## 已确认的问题与修复

| 层次 | 实际证据 | 通用修复 |
| --- | --- | --- |
| 观察 | 装饰性字段标题被当成区块；真实页面曾出现 37 个有字段区块，字段落入错误经历 | 有界字段行与标题范围判断；剔除选中值、箭头和弹出选项；不采用公司域名或生成类名 |
| 观察 | 年/月输入、学校和学历控件被当成普通文本；手机号区号变成字段标签 | 通用选择控件根识别；日期单位及开始/结束角色；读取已提交显示节点的存在性 |
| 规划 | 同一城市问题在申请信息、求职意向中出现，合法映射被判重复 | 同一已知问题允许跨逻辑区块复用标量来源；不同经历索引和不同含义仍受校验 |
| 规划 | 工作区块、教育区块被混用；获奖日期借用了毕业年月 | 用已观察的记录区块、日期用途与端点限制候选来源，执行前独立校验 |
| 模型接口 | 服务商 HTTP 400 指向工具参数 schema 中空枚举 | 无候选资料的区块本地生成 `missing_profile`；不发送空 `enum`/空 `anyOf`；保留完整运行时校验 |
| 执行 | 一个选项的外壳和内容同时被扫描，导致唯一选项被判歧义 | 只合并包含关系中同标签的选项；不同实体的同名选项继续保留歧义 |
| 执行 | 年/月候选包含数字或带单位文字 | 按字段日期单位选择唯一数值相符候选，选择后关闭菜单并回读提交值 |
| 执行 | 年份选择后报 `REAL_PAGE_CHANGED`；节点、类型、区块、经历均一致，只有标签不一致 | Chrome 元素面板确认组件清空 `placeholder`；缓存同一选择节点上实际观察到的日期单位，继续校验其他身份条件 |
| 执行 | 选年后网页自动生成月份，月份被当成用户原有内容而跳过 | 只对同记录、同端点、同日期问题中原本为空的相邻日期控件记录本轮默认值；后续依据资料完成。现有值、用户改动、容器变化均保留 |
| 诊断 | 错误只剩“页面变化”或 HTTP 状态码 | 增加节点/标签/类型/区块/经历的五项布尔诊断，以及限长、闭合的模型接口分类；不回传错误原文、请求体或资料值 |
| 边界 | “同步更新在线简历”复选框被当成经历规划对象 | 规划器与执行器一致，将复选框列为人工处理 |

## 真实页面结果

修复后，同一页面观察到 **11 个有字段区块、106 个字段、0 个标签缺失**。不含字段的按钮容器单独计数，不代表额外经历。

分次执行中新增了 **11 张经历卡片**：实习 1、项目 1、获奖 9。教育第二张卡片已在后续轮次开始前存在，不计入本轮 Agent 添加数。页面只有获奖区块时，资料中的 5 条获奖与 5 条竞赛合并为 **10 张卡片**。

最近一轮 Chrome 执行记录显示：

- 核验写入 **32 个字段**，当轮新增 0 张卡片，控件执行失败 0。
- 教育/实习/项目年份、学校/专业/学历、项目名称及描述、语言掌握程度、10 条奖项名称进入后续核验。
- 全页诊断为资料缺失 41、歧义 5、保护或人工处理 17、未映射 0。资料缺失包括尚未提供的奖项日期和工作经历；不据此生成事实。
- 姓名、手机号及其他已有内容继续保护。

**这一轮 32 字段的结果不能证明日期全部正确。** 随后从页面与执行记录确认了选年自动生成月份的问题。日期联动修复已经完成生产执行器的虚构回归，最后一次构建成功；Mac 锁屏使新构建的扩展重新加载、真实月份核对与纠正仍待继续。此处保留验收边界，不把本地测试作为真实页面最终验收。

## 虚构回归

`src/fixtures/decorated-form.js` 使用虚构资料与控件层级，包含多层标题、嵌套选择器、重复选项节点、拆分年月、年月联动默认值及添加经历。不复制公司页面 HTML 或生成 CSS 类名。

生产观察、规划校验、添加、填写、逐项回读与最终复扫流程中：**35 个字段核验写入、3 张卡片新增、8 个联动日期默认值按资料完成、0 次提交、菜单全部关闭**。

负例确认：真实标题或单位改变、选择器容器替换仍使绑定失效；原有月份与后来改动的月份不会覆盖；奖项时间不能引用毕业时间，开始日期不能引用结束日期；空候选区块不请求模型；接口原文和未知参数不进入诊断。

最终 `npm test`：**166 项通过、0 项失败**；`npm run build:extension` 成功。本地服务已重启并确认运行。Chrome 中新构建加载与真实月份复核仍需解除锁屏后继续。
