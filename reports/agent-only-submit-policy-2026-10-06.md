# 0.7.9：移除网页屏蔽，保留 Agent 不提交

日期：2026-10-06。仅更新 `RESUME_AGENT`，原插件项目未改动。

## 用户确认的需求

Agent 不点击提交、投递或同类按钮；用户可以正常使用网页，包括手动操作提交按钮。填写任务不应暂停网页联网，也不需要额外恢复步骤。

## 实现

- 删除生产网络规则安装器、网页提交与请求拦截器、旧手动恢复流程以及公共查询允许名单模块。
- Manifest 更新为 0.7.9，权限仅为 `activeTab`、`scripting`、`storage`，扩展 ID 保持原值。
- 真实执行路径使用只读主框架脚本取得 `documentId`；保留活动标签页、精确网址、字段身份、资料来源与记录顺序检查。
- 保留受限填写与添加工具，以及提交类语义、声明、签名、已有内容的执行限制。
- 任务完成、失败或停止后清理隔离世界运行时的字段绑定与日期监听，不清空网页内容。
- 工具栏删除「本轮页面保护」与「恢复正常浏览」，不再读取或等待旧保护状态。
- 旧版残留规则与钩子由只做移除的迁移模块自动清理；不创建新拦截规则。
- 执行记录标记 `submissionPolicy: agent_actions_only`；不再生成暂停网页请求的统计。
