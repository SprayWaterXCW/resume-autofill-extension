# Resume Agent（建设中）

目标：让用户的资料库驱动一个可观察、可验证、可恢复的浏览器填表 Agent。它要能理解“毕业院校／毕业学校”等不同说法，按需要添加经历卡片，处理复杂控件，最后把填写结果留给用户检查。**任何提交简历、投递、报名或等价动作都不在 Agent 的能力范围内。**明确的“保存草稿”可以在确认页面语义和安全性后作为单独能力加入。

## 0.7.28 阶段记录：完整输入流程与填写模式

本轮修复「输入框有内容，网站仍认为未填」的通用输入流程。普通文本和多行说明在任务绑定的文档中通过 MAIN 世界完成输入、变更与失焦；当扩展面板或其他标签页持有焦点，目标缺少原生 `blur/focusout` 时，只补发这个已验证目标缺少的事件。网站中存在输入组件在变更时只更新内部值、失焦时才把答案传给业务表单的链路，因此只看 DOM 或组件值都不够。

工具栏新增「全部覆盖（默认）／只填空白」。偏好保存在扩展本地，每个标签页任务使用启动时固定的模式。没有资料来源的字段不清空；只读、禁用、上传、声明和签名等保持原有执行边界。空白模式在实际写入前再次检查用户是否已经输入。

执行记录区分「已核对输入组件状态」和「只完成控件选择或回读」，网站预览与保存结果单独核对。加入真实 React 的双层组件／表单模型测试，覆盖文本、多行说明、缺少原生失焦、拒绝状态更新、后续丢值、覆盖偏好与任务隔离。最终全量回归 **211 项通过**，扩展构建通过，普通 Chrome 已更新到 **0.7.28**。真实验收和中间未通过轮次见 [本轮报告](../reports/page-state-2026-10-06.md)，原理与技术讲解见 [第二十七课](lessons/27-page-state-and-fill-modes.md)。

## 0.7.26 阶段记录：真实遗漏修复与独立资料属性

重新规划携带已核验字段的来源占用关系，防止已使用的教育、实习等记录属性被借给另一个不兼容的目标。研究方向、其他语言能力、推荐人等使用独立语义约束。**网页回读一致不代表含义正确；执行失败数为零也不代表整页填写完整。** 各轮真实结果、遗漏与验证范围见 [本轮报告](../reports/observed-omissions-2026-10-06.md)，技术讲解见 [第二十六课](lessons/26-observed-omissions-and-profile-growth.md)。

民族使用明确的族别字段或经本地检查的投影，籍贯与户口位置分开，工作年限与经历结束日期分开。已核验字段退出后续模型规划；若后续回读发现值丢失，撤销凭据后才重新规划。网页自动锁定已填字段后，只为最终回读保留已有凭据；继续严格拒绝再次写入只读或禁用字段。目标含义改变、身份不唯一、锁定后值为空或已有值改变时不能据此取得成功回执。中间失败轮次保留在报告中。

### 按标签页独立运行与后台等待

任务绑定启动时的标签页和文档。切换到其他标签页、关闭面板后，继续填写原页面；可以在另一页再点击「开始填写此标签页」，各页有自己的模型连接、计划、进度、记录和停止按钮。刷新、跳转或关闭原页面只结束该页的任务。面板提示其他页正在运行的任务数量；资料保存与日期规则修改等所有任务结束后再进行。

网页里的短计时器在后台可能被 Chrome 限速，导致下拉菜单已选中却未通过稳定核验。0.7.18 由扩展后台调度短等待，通过扩展消息核对发送者、标签页和文档；不修改 Chrome 设置、网页 API 或页面可见性。实现原理见 [第二十五课](lessons/25-independent-tab-jobs.md)，实测和测试中的未通过项见 [多标签页验证](../reports/background-tabs-2026-10-06.md)。

使用方式：在 A 页启动 → 切到 B 页启动 → 继续浏览其他页面 → 回到各页打开工具栏查看自己的进度。运行中的页面请保持打开；刷新或导航会停止该页任务。

## 通过网页配置个人资料

1. 在普通 Chrome 中点击 Resume Agent 工具栏图标。
2. 点击「编辑资料 · 打开网页」。
3. 从左侧选择资料分类，在右侧表单中填写或修改。已导入的资料会自动显示。
4. 教育、实习、项目、家庭成员、获奖和竞赛等多条记录，用分类中的「添加」按钮增加。
5. 点击右上角「保存资料」或每个分类下方「保存全部资料」。
6. 看到「资料已保存」后，回到招聘网页再启动 Agent。

基本信息包含身高（厘米）和体重（公斤）；家庭成员包含姓名、关系、年龄、工作单位、职务、联系电话及政治面貌。渠道在「求职偏好」中填写。获奖和竞赛在「补充信息」中按卡片分别填写，每条都有四个独立字段及删除按钮。只知道年月的经历日期可以保留到月，日期补全规则仍在扩展面板中设置。

「语言能力」除语言、总体熟练程度、成绩外，增加「听说能力、读写能力」。网页拆成分项时使用独立分项资料，留空就报告资料缺失；不会拿考试成绩或总体等级推测。保存资料后下一轮使用这些来源。

点击「＋ 添加获奖」或「＋ 添加竞赛」，填写名称、级别、等次、详细信息。级别可选国际级、国家级、省级、市级、区县级、校级、院级，暂时不清楚就保持「未确认（暂不填写）」。等次填写证书或通知上的一等奖、二等奖、金奖等，没有则留空。详细信息可记录时间、颁发单位、成果和相关说明。旧资料中的第一行迁入名称，其余行迁入详情；单行内容先完整保留在名称中，可直接调整。已从旧资料明确提取的级别和等次请核对。所有名称都可修改，增删记录会保留其他未保存字段，填写完成后点击「保存资料」。

保存资料同时保存所有分类。未保存时离开页面会提醒；另一窗口更新资料时，本页不会覆盖未保存修改，保存会检查版本冲突。任一标签页正在扫描、规划或填写时暂时不能保存资料，等所有任务结束后重试。

「导出备份」下载当前表单内容，便于换机。通过编辑器「导入备份」后先核对，再点击「保存资料」生效。资料保存在此 Chrome 用户资料中的扩展本地存储；扩展更新会保留资料，换机或卸载前应导出备份。编辑器可以离线打开，开始 Agent 填写仍需要下文的模型服务。

## 运行

要求 Node.js 22 或更新版本。在本目录执行：

```sh
npm ci
npm run demo
npm run demo:web
npm test
npm run bench
```

`demo` 输出单次动作轨迹；`test` 检查运行机制与安全边界；`bench` 给出合成任务成功数、危险动作阻断数和后置验证失败数。评测数据全是虚构数据，不需要 API Key，也不会访问招聘网站。

`eval:benchmark` 是更完整的独立判分任务集，覆盖同义字段、多段经历、获奖／竞赛分流、自动补全、下拉选项、故障恢复和提交风险。除强制安全探针外，它会调用 `.env.local` 配置的模型；运行前先按下文配置 API Key。判分规则和首轮结果见 [评测说明](evaluation.md)。

### 在 Chrome 中看填写过程

运行 `npm run demo:web` 后，打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。

1. 点击「快速演示」可先看不调用模型的完整过程。
2. 点击「重置表单」恢复初始的一张空白卡片。
3. 点击「真实模型填写」让 `.env.local` 中配置的模型决定每一步。页面会自动重置；右侧最新步骤默认展开，之前的步骤可以点击查看。每张卡片显示观察、模型的简短理由、预期动作、实际执行和页面回读。

本地服务只监听 `127.0.0.1`。API Key 只在本地 Node 服务中使用，浏览器不会获得它。模型收到页面的字段标签和资料库的字段路径，不收到简历值。当前页面只用虚构资料，提交按钮不可用，也没有投递接口。按 `Ctrl+C` 可以停止服务。

真实模型的只读规划小样例可运行 `npm run eval:plan -- --output=reports/plan-model-smoke-2026-10-04.json`。它验证英文教育标签、获奖/竞赛合并、获奖/竞赛分区三种合成元数据任务，不操作招聘网站，也不能代表跨网站填写成功率。

### 可选：使用自己的模型跑合成评测

复制 `.env.example` 为 `.env.local`，在本机填写 `RESUME_AGENT_API_KEY`，然后运行 `npm run eval:model`。默认配置使用 DeepSeek 的 OpenAI 兼容接口；你也可以设置 `RESUME_AGENT_BASE_URL` 和 `RESUME_AGENT_MODEL`。密钥文件被 Git 忽略，命令不会输出密钥、真实简历值或模型原始响应。这个命令只把虚构资料的**字段路径和标签**、模拟页面结构发送给模型，不读取旧版真实简历，也不打开招聘网站。模型调用可能产生费用。

运行完整合成评测：

```sh
npm run eval:benchmark -- --output=reports/baseline.json
```
