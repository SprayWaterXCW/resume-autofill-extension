# 第二十二课：约束 Agent 的动作，保持网页正常使用

日期：2026-10-06；对应版本：0.7.9。

## 这一步要解决什么

用户确认的需求是：Agent 负责填写、添加经历和核验；提交和投递由用户决定。用户仍然需要正常使用招聘网站的控件。

之前的实现额外暂停了网页网络，改写了网页请求与提交方法，并拦截提交按钮的点击事件。网站的学校搜索、专业候选、页面刷新和用户手动按钮也会受到影响，填写后还需要手动恢复浏览。0.7.9 删除这些机制，工具栏直接提供「开始填写」和「停止填写」。

这一步位于执行层和浏览器入口层：资料结构、模型语义规划、经历分组和回读核验继续使用原来的流程。

## Agent 如何继续拒绝提交

### 1. 工具允许名单

模型只能提出实现过的受限动作。它没有通用点击、表单提交、网页导航或任意脚本执行工具。填写动作的参数是已经观察到的字段 ID 和本地资料路径，添加动作的目标是已经观察到的经历分组。

这叫能力限制：可用能力由程序定义，模型无法通过一段自然语言解释获得额外权限。模型提出未知工具、未知字段或无效资料路径时，程序会拒绝执行。

### 2. 动作前核验

添加经历必须命中已观察的添加候选，检查控件类型、当前文字、所属区块和记录结构。提交、投递、注册、签署及类似语义不能作为添加按钮。普通按钮默认的 `type=submit` 也不能被 Agent 当作添加按钮。

复杂控件中的确认按钮必须属于该字段的局部弹层，例如地区选择器；它不能把整页的提交按钮当作选择器确认。已有资料、声明、签名等仍按既有规则保护或留待人工。

这里拒绝的是 Agent 的动作请求。执行器不会给整个网页注册阻止用户点击的捕获监听器，也不会禁用页面原有按钮。

### 3. 文档与字段身份

不再用「安装网页保护」取得文档身份。执行器用只读脚本读取当前主框架的 Chrome `documentId`，后续动作都绑定这个文档。

`tabId` 标识标签页；`documentId` 标识当前网页文档。同一个标签页刷新后，即使网址完全相同，文档身份也已经变化。旧模型建议不能继续写入新文档。同一文档内的控件节点重建仍使用此前的结构对比与一次重绑恢复。

这解决任务与网页状态的一致性问题，不需要暂停网络。

## 删除了哪些浏览器干预

| 原机制 | 0.7.9 的行为 |
|---|---|
| Chrome DNR 请求阻断规则 | 新任务不创建规则，Manifest 移除该权限 |
| 改写 fetch、XHR、sendBeacon、window.open | 保留网站原有实现 |
| 改写 form.submit、form.requestSubmit | 保留网站原有实现 |
| 捕获并拦截网页点击、提交事件 | 删除全页事件拦截 |
| 公共学校、专业、地区请求允许名单 | 删除；查询按网站原有行为正常发送 |
| 任务结束后等待手动恢复 | 删除该状态和工具栏按钮 |

网站原有的自动保存、请求和表单行为也按网站自己的逻辑运行。Agent 对外提供的边界是受限动作执行。

任务结束时仍会清理扩展隔离世界里的日期监听、字段绑定和私有回读凭据。这是运行时资源清理，不会清空网页字段或修改网站 API。

## 如何平滑更新旧版本

`legacy-page-cleanup.js` 只有移除能力：调用旧页面钩子的 `release()`，清理扩展自身历史会话规则，不安装新规则。更新启动时尝试清理已保存的旧任务，用户打开工具栏时再次尝试清理当前页面，兼容旧后台状态丢失或临时标签页访问已到期的情况。

清理旧文档时仍绑定原 `documentId`，不把旧任务的清理代码套到刷新后的替代文档上。旧页面钩子的释放方法也使已缓存的请求包装函数恢复工作，网页中的填写内容保持原样。

Chrome 官方说明会话规则在安装扩展新版本时清除；开发重载下存在 API 时，我们还只移除本扩展拥有的历史规则 ID。[Chrome DNR 规则生命周期](https://developer.chrome.com/docs/extensions/reference/api/declarativeNetRequest#rules-and-rulesets)。

## 怎样验证这次改变

验证包含两个独立方向：

- 运行生产执行器的虚构任务，确认填写 23 项、添加 7 张卡片，提交计数仍为 0；欺骗性的「添加并提交」和默认提交按钮不能成为 Agent 动作。
- 从用户侧触发模拟提交和 `requestSubmit()`，确认页面处理器照常执行；普通 GET、POST、XHR、信标与图片请求不被拦截。

另外测试规划失败、未核验写入、成功写入和同网址刷新：这些路径均不会安装或保留页面屏障。回归包括旧任务迁移、无网络权限、规则状态丢失、文档替换以及保留已有字段值。

普通 Chrome 实测和完整回归结果见 [本轮报告](../../reports/agent-only-submit-policy-2026-10-06.md)。
